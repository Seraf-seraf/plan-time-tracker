# Трекер планов 0.6.0

Приватный трекер сохраняет исходный Markdown плана, текущие статусы этапов, серверные интервалы работы и оценки времени ATLM. Рабочий сайт: https://plan-time-tracker.s-e-r-a-f.chatgpt.site.

Этап содержит идентификатор, порядок, название, текст, текущий статус и версию. SetStepStatus напрямую меняет текущее состояние RUNNING-плана. Доступны PENDING, RUNNING, BLOCKED, FAILED и DONE. Запись статуса не управляет таймером.

StartPlan, PausePlan, ResumePlan и FinishPlan задают интервалы конкретного плана. Для обычного завершения все его этапы должны быть DONE. Явное завершение с незавершёнными этапами сохраняет причину. Параллельные планы независимы; аналитика общего времени объединяет пересекающиеся интервалы.

Модель попыток выполнения этапов, аренды исполнителя, история статусов и старые записи результатов/проверок удалены из API и хранилища. Квитанции команд обеспечивают идемпотентность и восстановление после потери ответа. Исходные планы, текущие статусы, интервалы, оценки и обучающие данные сохраняются.

## Обновление схемы

`0021_simple_steps.sql` переносит текст этапов в `plan_steps.content`, сохраняет текущие требования без изменения JSON/digest и удаляет таблицы старого исполнения. Обе схемы миграций проверяются на заполненном снимке с открытым интервалом и действующей обученной моделью.

У рабочего Sites отдельный исходный Git-репозиторий и собственная цепочка Drizzle 0000–0006. Его старые SQL, snapshots и journal сохраняются неизменными; 0006 эквивалентна канонической 0021. Push в GitHub сам по себе не публикует сайт.

# Обучить модель прогноза ATLM

Прочитайте `GetTrackerInfo.assessments.atlm.registry` и `tools/list`. Для нового обучения сверьте `registry.teacherRecipeIds`, `registry.defaultTeacherRecipeId` и формат датасета из `registry.teacherDataset`. Для работы с трекером нужны права владельца.

## Снимок и преподавательская разметка

Начните новое обучение со свежего снимка. Используйте уже сохранённый снимок или датасет, если пользователь указал его явно или вы продолжаете тот же запуск. Для точного воспроизведения используйте архивные входы и версию тренера того запуска.

Перед разметкой откройте правила подготовки. На каждый завершённый неудалённый план подготовьте одну строку. Исправьте признаки и активное время по материалам плана и уточнениям пользователя. Применяйте подстановки и допустимые неизвестные значения по правилам конкретного поля. [Подготовка датасета по схеме](references/dataset.md).

Если обязательное значение всё ещё неизвестно, до сохранения и обучения покажите пользователю ID и название плана, поле, проверенные источники и конкретный вопрос. Для пропуска завершённого неудалённого плана нужно явное решение пользователя по этому плану. Удалённые и незавершённые планы исключайте по их статусу.

Сверьте с исходным снимком каждую строку сохранённого экспорта. До обучения сообщите число включённых, исправленных и исключённых планов, перечислите все исключения с ID, названием и причиной. Если поручена только подготовка датасета, завершите работу после этой сверки и отчёта.

## Передача файлов

Перед первой передачей откройте справочник с командами выгрузки и загрузки, проверкой SHA-256 и действиями после прерывания. [Передача файлов через MCP](references/transfer.md).

## Локальный рецепт и проверка

Для обучения нужен checkout с тренером, который поддерживает выбранный рецепт, и Node.js 24. Выполните локальный запуск и сверьте состав артефакта. Для v4 проверьте все пригодные строки датасета. При точном воспроизведении сравните состав с исходным запуском. Если поручено только обучение, завершите работу после проверки файлов. [Рецепт, запуск и проверка результата](references/training.md).

## Зарегистрировать и опубликовать

Для проверки сохранённой модели откройте её в реестре. Регистрация сохраняет пакет модели. Активация назначает ревизию для следующих прогнозов. Выполняйте регистрацию, активацию или откат в пределах поручения. [Инструменты реестра и публикация](references/registry.md).

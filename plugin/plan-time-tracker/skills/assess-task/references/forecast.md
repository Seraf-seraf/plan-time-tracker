# Чтение оценки и прогноза ATLM

## Выбрать запрос

| Что требуется | Запрос |
| --- | --- |
| Прочитать требования перед оценкой всего плана | `GetTaskAssessment` с одним `planId`. Передайте полученный `currentRequirementsDigest` как `expectedRequirementsDigest` при сохранении. |
| Проверить сохранённую оценку | `GetTaskAssessment` с `planId` и `assessmentId`. Для чтения конкретной версии укажите `revision`. |
| Посмотреть расчёт для переданных признаков до запуска | `EstimatePlanTime` с `planId`, `expectedRequirementsDigest` и `agentTask`. Это предварительный расчёт без сохранения оценки. |
| Прочитать готовность и прогноз всего плана | `GetSavedEstimate` с `planId`. До запуска сервер рассчитывает текущий прогноз по сохранённым признакам. После первого `StartPlan` возвращает исходный зафиксированный прогноз. |

## Проверить готовность

Первый `StartPlan` требует `assessmentReadiness.status=READY`. При таком статусе запуск доступен и при `serverEstimation.status=UNAVAILABLE`. Допустимые `UNKNOWN` с указанным проверенным источником, а также допустимые `BLOCKED` и `MISSING` совместимы с готовностью оценки.

| Состояние | Действие |
| --- | --- |
| Оценка отсутствует | Создайте серию. Попытка первого запуска без оценки возвращает `ASSESSMENT_REQUIRED`. |
| `INCOMPLETE` | Заполните обязательные поля, значения и основания по `missingPaths`. |
| `INVALID` | Исправьте тип, значение из закрытого списка, связь или уникальность по `invalidPaths`. |
| `OUTDATED` | Заполните признаки текущей схемы и сохраните ревизию. |
| `STALE` | Перечитайте требования и сохраните ревизию с актуальным digest. |

## Прочитать точку и интервал

`serverEstimation.pointMs`, `interval.lowerMs` и `interval.upperMs` измеряются в миллисекундах активного времени `PLAN_ACTIVE`. Первый запуск фиксирует прогноз на полное время плана. Учёт фактического времени ведётся отдельно.

Действующая ревизия закрепляет точечный метод OLS, Ridge или Bayesian. Для интервала она может использовать `BAYESIAN_PREDICTIVE` или `BAYES_QUANTILE`. Точка может быть доступна при недоступном интервале. При достаточной истории запасной метод `historical-median` возвращает точку без интервала. При отсутствии пригодных данных прогноз недоступен.

Номинальный охват интервала составляет 80%. `accuracy:'EXPERIMENTAL'` описывает состояние исторической проверки прогноза. Допуск ревизии к активации определяется отдельно. [Регистрация и активация](../../train-model/SKILL.md)

| Поле отчёта | Что измеряет |
| --- | --- |
| `forecastRate` | Доля сопоставимых планов с доступной точкой. |
| `intervalAvailabilityRate` | Доля сопоставимых планов с доступным интервалом. |
| `intervalCoverage` | Доля попаданий факта среди планов с доступным интервалом, включая попадания на его границы. |

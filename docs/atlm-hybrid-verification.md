# Локальная приёмка гибридного прогноза ATLM

Дата: 13 ноября 2026 года, Asia/Omsk. Реализация выполнена в main поверх 4407690. Подготовлен локальный кандидат; коммиты, push, CI, публикация Site, установка hosted-плагина и обучение рабочего трекера не выполнялись.

## Проверенное поведение

Метод atlm/agent-v3-hybrid с policyVersion=1 сравнивает OLS и ridge(lambda=1) по более ранним результатам, сохраняя отдельный historical-median. Полный ранг сам по себе не даёт OLS приоритета. Ridge сохраняет девять исходных признаков и допускает зависимые/широкие матрицы. Ошибки учитывают доставленный запасной прогноз на тех же задачах.

Протокол 2 выбирает наблюдавшиеся версии до capturedAt, затем применяет eligibility и sourceAvailableAt. Для каждого внешнего случая выбор метода также использует только более ранние проверки. SQL-префиксы очереди совпали с чистым воспроизведением неизменяемого журнала на существующей численной фикстуре. Загрузка фактов после задач не создаёт фиктивных прошлых сравнений.

Подтверждены отдельный legacy OLS agent-v2, совместимость чтения и защищённой записи его прогноза, ранняя экспериментальная модель, предпочтение медианы при равной ошибке, выбор OLS при достаточных собственных сравнениях и лучшей ошибке, защита incumbent, owner/CAS, lease/fence, возобновление BASE_CASE и сохранение исходного snapshot. Нулевое время, неизвестные runtime и неподдерживаемые обязательные категории различаются с техническими ошибками.

Старые SQL и миграционные фикстуры не изменены. Проверка заполненной миграции сохранила прежние записи; её последующая попытка обучения на постоянных длительностях теперь корректно предпочитает медиану. Условия сохранности данных в этом тесте не ослаблялись.

Новые issuedPrediction включают медиану с modelId=null; actualMs остаётся измеренным интервалом. Старые sample-версии не переписываются и массового backfill нет. Проверены текущий read-only PLANNED и неизменяемый прогноз после первого StartPlan, включая legacy без forecast_json.

## Ограничения результата

В исследованной выборке 16 из 25 планов — похожие HTTP-серверы. Снижение средней ошибки на этой копии не доказывает устойчивого превосходства на новых видах работы. Пятисравнительный минимум не является гарантией статистической независимости; нужны последующие реальные результаты, а не тестовое заполнение рабочего трекера.

Ретроспектива использует доступный префикс перед задачей и не воспроизводит точный календарь обновления модели через каждые два плана. Ошибки реально выданных frozen-прогнозов учитываются отдельно. Работа таймера измеряет включённые рабочие интервалы, включая ожидание без PausePlan; это не CPU-время агента.

Проверены локальный Worker, SQLite-обвязка, контролируемые прерывания и собранный артефакт. CPU-лимит опубликованного Sites, внешний CI, действительный hosted ledger и работа новой версии после публикации этой приёмкой не подтверждаются. Опубликованный сайт и рабочие данные не менялись.

Критерии A01–A17 [плана реализации](atlm-hybrid-implementation-plan.md#51-общие-критерии-приёмки) закрыты в локальном объёме: численные тесты — A01–A05; журнал/политика/метрики — A06–A08; очередь/совместимость/неизменность — A09–A13; браузер — A14; инструкции и общая сборка — A15–A16; проверка состава индекса, частной копии и внешних действий — A17.

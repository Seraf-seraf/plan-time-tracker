# Экспорт JSON, формат 3

`GET /api/export` возвращает один согласованный снимок владельца с `formatVersion:3`, `exportedAt`, `timezone`, `summary`, `plans` и `training`. Чтение не меняет данные и таймеры. Удалённые планы включаются в `plans`, но исключаются из итогов. `totalActiveMs` объединяет интервалы планов; `sumPlanActiveMs` суммирует их отдельно. Неизвестное измерение обозначается null, измеренный ноль — 0.

План содержит исходный Markdown, метаданные, текущие статусы этапов, интервалы, ревизии оценок и `frozenForecast`. Интервалы этапов учитывают паузы плана. Даты сохраняют точность instant или dateOnly и часовой пояс. `finishExceptions` содержит причины явного завершения с незавершёнными этапами.

`training.samples` содержит версии примеров с исходными признаками, пригодностью, фактом и `issuedPrediction`; в прогнозе сохраняются точка и реально выданный интервал. `training.models` содержит версии текущего метода, manifest и метрики. `training.attempts` содержит попытки, диагностику, кейсы, выбранные методы и причины отказа или ошибки. Экспорт не включает внутреннюю очередь и коэффициенты модели и не является полным резервным архивом приложения. Подробности полей прогноза и метрик — в [ATLM](atlm.md).

# G1. Проверка приватности

## ID

G1

## Цель

Доказать:

- owner одинаково определяется UI и серверной частью;
- нельзя получить чужие данные;
- прямые обращения защищены.

## Входы

- доступ к Sites runtime;
- тестовые аккаунты.

## Задачи

G1-T1. Проверить идентификацию владельца.

G1-T2. Проверить чтение чужого Plan.

G1-T3. Проверить запись чужого Plan.

G1-T4. Проверить прямой доступ без UI.

## Артефакты

- отчёт проверки приватности;
- список подтверждённых механизмов авторизации;
- результаты негативных тестов.

## PASS

- сервер устанавливает ownerId;
- чужие планы недоступны;
- UI и MCP используют одинаковую идентичность.

## FAIL

Действия:

- остановить работу с пользовательскими данными;
- найти поддерживаемый механизм приватности;
- не использовать скрытые ссылки как замену авторизации.

# План реализации приложения «Учёт времени реализации планов»

## 0. Назначение и правила исполнения плана

Цель проекта: создать приватное приложение в ChatGPT Sites для учёта активного времени реализации завершённых планов, хранения истории Start/Pause/Resume/Finish, связи планов с GitHub-репозиториями и предоставления аналитики.

Главная единица анализа: завершённый план. Коммиты GitHub являются только контекстом и проверяемой связью, но не измеряют трудозатраты и качество работы. Источник истины по времени: сохранённые серверные интервалы работы. Вставленный текст

План не предполагает автоматического рабочего расписания. Таймер в состоянии RUNNING продолжается до явной команды Pause или Finish, включая ночи и выходные. Вставленный текст

Все возможности платформы Sites, GitHub runtime-доступа и MCP до проверки считаются неподтверждёнными. Проверки G1–G6 обязательны до разработки функциональных частей. Вставленный текст

- Plan;
- WorkInterval;
- PlanEvent;
- CommandReceipt.

## Проверка

Для каждой команды изменения:

- StartPlan;
- PausePlan;
- ResumePlan;
- FinishPlan;

создаётся сценарий сбоя:

1. начало транзакции;
2. изменение одной части данных;
3. искусственный сбой;
4. проверка состояния.

## PASS

После сбоя:

- нет PlanEvent без соответствующего изменения Plan;
- нет открытого WorkInterval без RUNNING;
- нет CommandReceipt без результата;
- нет частичного состояния.

## FAIL

Работа блокируется до появления доказанного атомарного механизма.

---

# 4. G2: уточнение идемпотентности

## Правило обработки CommandReceipt

Порядок:

1. Получить `commandId`.
2. Найти существующий CommandReceipt.
3. Если найден:
   - сравнить payloadHash.
4. Если hash совпадает:
   - немедленно вернуть сохранённый snapshot;
   - вернуть предыдущий результат;
   - НЕ проверять текущий expectedVersion.
5. Если hash отличается:
   - вернуть:

```
IDEMPOTENCY_KEY_REUSED
```

6. Если receipt отсутствует:
   - проверить expectedVersion;
   - выполнять команду.

Это исключает повторное применение уже выполненной команды после изменения состояния.
